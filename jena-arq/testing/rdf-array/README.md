# The rdf-array contrib suite

A copy of [rdf-tests-contrib](https://github.com/rdf-array/rdf-tests-contrib) (`rdf/`, `sparql/`):
the Turtle-, TriG-, N-Triples-, N-Quads- and SPARQL-array tests every rdf-array implementation
shares and no W3C suite contains. `rdf-tests-contrib.commit` records the commit it was copied from;
`update.sh` refreshes it. Do not edit the copy; change rdf-tests-contrib and copy again.

Run by `org.apache.jena.external.Scripts_RdfArrayContrib` (the RDF syntaxes) and
`Scripts_RdfArrayContribSPARQL` (SPARQL), both in `ARQTestSuite`.
